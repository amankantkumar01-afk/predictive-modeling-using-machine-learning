# Exploratory Data Analysis - Student Performance

This is a student-level EDA project prepared for a Data Science internship.

## What I did
- Checked the dataset shape
- Checked missing values and duplicate rows
- Used simple median imputation
- Removed duplicate rows
- Calculated statistical summaries
- Checked correlation
- Created basic charts
- Wrote observations and limitations

## Dataset
The dataset is a synthetic academic dataset for demonstration and learning.

## Files
- `student_performance_eda.csv` - raw dataset
- `cleaned_student_performance_eda.csv` - cleaned dataset
- `eda_analysis.py` - Python analysis script
- `Project_Report.txt` - project report
- PNG files - visualizations
- `requirements.txt` - Python libraries

## How to run
Install:
`pip install -r requirements.txt`

Then run:
`python eda_analysis.py`

This project uses Python, Pandas, NumPy and Matplotlib.
