1. INTRODUCTION
In this project, I worked on a simple machine learning problem related to student performance. The purpose was to build a model that can predict whether a student may pass or fail using a few basic academic features.

2. OBJECTIVE
The main objective is to apply supervised machine learning and understand the process of training, testing and evaluating a predictive model.

3. DATASET
I used a small student performance dataset. It contains study hours, attendance percentage and previous score as input features. The target column is Passed, where 1 means Pass and 0 means Fail.

4. DATA PREPARATION
First, I loaded the CSV file using Pandas. I selected the three input columns and separated the target column. The dataset was divided into training and testing data using an 80:20 ratio.

5. MACHINE LEARNING MODELS
I used two classification algorithms:
- Decision Tree Classifier
- Random Forest Classifier

Decision Tree is easy to understand because it makes decisions using conditions. Random Forest combines many decision trees and can usually give more stable predictions.

6. MODEL EVALUATION
I used accuracy score and classification report to compare the models. I also created a confusion matrix for the Random Forest model. A ROC curve was generated to understand the classification performance at different thresholds.

7. RESULT
The models produced reasonable predictions on the test data. The exact accuracy is printed when the Python file is run, so the result can be reproduced instead of manually entering a fixed value.

8. CONCLUSION
This project gave me practical experience with supervised machine learning. I learned how to load a dataset, select features, split data, train classification models and evaluate their performance using accuracy, confusion matrix and ROC curve.

9. FUTURE IMPROVEMENT
In future, I can use a larger real-world dataset, perform more detailed data cleaning, tune model parameters and compare more algorithms.
